# QuietPay

Payment links for freelancers and small businesses: the client pays with a supported token on a supported chain, and the merchant receives an exact USDC amount in their NEAR account through NEAR Intents 1Click. Built for the NEAR Hackathon, Real-World Money track.

- **Live demo:** https://quietpay-rust.vercel.app (mainnet; private mode on; a completed payment moves real funds)
- App, setup and demo steps: [`quietpay/README.md`](quietpay/README.md)
